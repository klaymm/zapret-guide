## ЭТАП 0: ПОДГОТОВКА СИСТЕМЫ

> Этот этап решает **90% всех проблем** ещё до установки.

### 0.1 — Проверка прокси-настроек

Вирусы и старые VPN часто оставляют здесь мусор, из-за которого запрет не работает.

1. Нажмите `Win + R`, введите `inetcpl.cpl`, нажмите Enter
2. Перейдите на вкладку **Подключения** → кнопка **Настройка сети** (внизу)
3. Убедитесь, что настройки соответствуют таблице:

| Параметр | Должно быть |
|---|---|
| «Использовать прокси-сервер...» | ❌ Снято |
| «Автоматическое определение параметров» | ✅ Установлено (или снято всё) |

### 0.2 — Конфликтующие программы

**AdGuard Desktop**
Его сетевой драйвер конфликтует с WinDivert. Два варианта решения:
- **Простой:** Полностью отключите фильтрацию на время настройки
- **Правильный:** Откройте AdGuard → Настройки → Сеть → Исключения → добавьте `winws.exe` и `Discord.exe`

> Браузерное расширение AdGuard конфликтов **не** вызывает.

**Антивирусы (Kaspersky, Dr.Web и др.)**
WinDivert — легитимный инструмент перехвата трафика, однако антивирусы часто определяют его как угрозу и удаляют из папки `bin`. Добавьте папку `C:\zapret` в исключения ещё **до** установки.

**Intel/Rivet Killer NIC**
Актуально для материнских плат ASUS ROG, MSI, Alienware с адаптерами Intel Killer E2400, E2500, E2600, E3000. Их «умное» управление трафиком нарушает перехват пакетов.
**Решение:** Killer Control Center → «Bandwidth Control» / «Advanced Stream Detect» → отключить.

**Виртуальные сетевые адаптеры (Radmin VPN, Hamachi, TAP)**
Начиная с версии 1.8.0 запрет конфликтует с виртуальными адаптерами. Симптомы: высокий пинг, обрывы, в крайних случаях каскадный отказ всех адаптеров.
**Решение:** Диспетчер устройств → Сетевые адаптеры → удалите все виртуальные, оставив физические (Ethernet, Wi-Fi). Radmin/Hamachi для локальных игр запускайте только при выключенном запрете.

**Сервисы-паразиты**
`Win + R` → `services.msc`. Найдите и **остановите** (тип запуска → «Отключена») всё, что содержит: `Killer`, `SmartByte`, `Check Point`, `Cisco AnyConnect`, а также любые VPN-сервисы.

**VPN-клиенты и Cloudflare WARP**
Cloudflare WARP **может работать совместно** с запретом: запрет обходит блокировки РФ-провайдеров, а WARP даёт нероссийский IP для сервисов, блокирующих РФ (ChatGPT, Gemini). Но WARP может конфликтовать с некоторыми стратегиями — для диагностики временно отключите. Остальные VPN (OpenVPN, Wireguard, Tunnelbear, Mullvad) отключите полностью.

## ЭТАП 1: ГЛОБАЛЬНАЯ ОЧИСТКА

> [!CAUTION]
> Нельзя устанавливать новую версию поверх старой или поверх GoodbyeDPI. Это одна из самых частых причин поломки.

### 1.1 — Остановка служб

Откройте **CMD от имени Администратора** и выполните по очереди:

```cmd
sc stop windivert
sc stop zapret
sc stop goodbyedpi
```

> «Служба не установлена» — это нормально, продолжайте.

Удалите старый драйвер:
```cmd
sc delete windivert
```

### 1.2 — Полное удаление файлов

Используйте утилиту [Everything](https://www.voidtools.com/) — она индексирует всё мгновенно.

Найдите и удалите **папки** с именами: `zapret`, `discordfix` (или `discord fix`), `goodbyedpi`, а также каталоги, в которых лежит `general.bat`.

> ⚠️ Не трогайте системные файлы Windows. Удаляйте только то, что скачивали самостоятельно.

## ЭТАП 2: СБРОС СЕТЕВЫХ НАСТРОЕК

Обязателен, если ранее были VPN/прокси, а также при ошибке «**Epic Games находится в автономном режиме**».

Откройте CMD от имени Администратора и выполните **все команды**:

```cmd
netsh int ip reset
netsh winhttp reset proxy
netsh winsock reset
netsh interface ipv4 reset
netsh interface ipv6 reset
netsh int ipv4 set dynamicport tcp start=10000 num=30000
ipconfig /flushdns
```

> 🔴 **После выполнения обязательно перезагрузите компьютер.**

## ЭТАП 3: УСТАНОВКА И НАСТРОЙКА

### 3.1 — Скачивание

1. Скачайте последний релиз: [github.com/Flowseal/zapret-discord-youtube/releases](https://github.com/Flowseal/zapret-discord-youtube/releases)
2. Распакуйте архив **строго в корень диска**:

| ❌ Плохо | ✅ Хорошо |
|---|---|
| `C:\Users\Вася\Desktop\zapret` | `C:\zapret` |
| `D:\Загрузки\Новая папка\zapret` | `D:\zapret` |

> Кириллица, пробелы и длинные пути вызывают ошибку `WinDivert64.sys not found`.

### 3.2 — Настройка HOSTS

#### Вариант А — Zapret (стандартный)

> ℹ️ Данный метод решает проблему подключения к голосовым серверам **финского региона**.

1. Запустите `service.bat`
2. Выберите пункт **8 (Update hosts file)**
3. Скопируйте весь выведенный текст
4. Откройте **Блокнот от имени Администратора** → Файл → Открыть → `C:\Windows\System32\drivers\etc` → файл **hosts**
5. Пролистайте в конец, добавьте пустую строку, вставьте текст, сохраните

> Если сохранение недоступно — Блокнот открыт без прав администратора.

#### Вариант Б — Разблокировка множества сервисов (ChatGPT, Instagram и др.)
1. Скачайте [RAW hosts от V3nilla](https://raw.githubusercontent.com/V3nilla/IPSets-For-Bypass-in-Russia/refs/heads/main/Разблокировка%20множества%20сервисов(пример%20-%20ChatGPT)/hosts)
2. Уберите расширение `.txt`: Проводник → Вид → Расширения имён файлов → переименуйте `hosts.txt` в `hosts`
3. Скопируйте в `C:\Windows\System32\drivers\etc` с заменой

### 3.3 — Подбор стратегии

1. В `service.bat` выберите **11 (Run tests)**
2. Нажмите **1 (HTTP/HTTPS check)** → **2 (Scan selected)**
3. Введите стратегии *(самые популярные для РФ)*:
   ```
   1(alt),3,9,10,11,12
   ```
4. Ищите конфигурацию, где **HTTP** и **TLS 1.2** везде зелёные (`Check: OK`). Запомните её номер.

> 💡 Если ни одна не даёт зелёного — расширьте список: `2,4,5,6,7,8,fake tls,simple fake`

### 3.4 — Установка службы

1. Закройте окно сканирования
2. В `service.bat`: **2 (Remove service)** → **1 (Install service)**, указав номер успешной стратегии

> ⚠️ При ручном переборе закрывайте предыдущий батник **перед** запуском следующего.
