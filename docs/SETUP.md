# Установка и настройки сети

[Оглавление](../README.md)

Начните с [быстрого старта](../README.md#быстрый-старт). При обновлении сначала сохраните свои настройки и уберите старую службу.

## Глобальная очистка

Используйте этот порядок при переходе со старой сборки, если остались несколько папок с zapret или в диагностике обнаружен другой обход.

1. Откройте старую папку --> `lists`. Скопируйте свои файлы `*-user.txt` и запишите отдельно строки, которые сами добавляли в `ipset-all.txt`. Если правили системный `hosts`, сохраните его копию [по инструкции ниже](TELEGRAM.md#hosts-для-discord-и-telegram). Запишите имя стратегии из `3. Check Status`, если использовали автозапуск. Если не помните путь к папке, воспользуйтесь поиском из шага 3, затем вернитесь сюда.
2. [Закройте ручной запуск](#как-выключить-и-включить-zapret). В старой папке откройте `service.bat` --> `2. Remove Services`. Для GoodbyeDPI и других инструментов, которыми больше не пользуетесь, запустите штатное удаление службы из их папки. Если другие обходы ещё нужны, остановите их для проверки и сохраните их файлы.
3. Если папку потеряли, откройте [Everything](https://www.voidtools.com/) или поиск в Проводнике. По очереди ищите `zapret`, `discordfix`, `discord fix`, `goodbyedpi` и `general.bat`. По найденному BAT нажмите правой кнопкой --> "Открыть расположение файла". Убедитесь, что папка относится к скачанной вами сборке. После резервного копирования переместите такие папки в корзину. Оставьте папку, из которой ещё надо удалить службу, до завершения шага 2.
4. Если старый `service.bat` отсутствует или после удаления Windows по-прежнему показывает старую службу, разверните блок ниже. После очистки перезагрузите ПК, распакуйте [официальный архив](https://github.com/Flowseal/zapret-discord-youtube/releases/latest) в новую папку и проверьте чистую стратегию. Затем откройте сохранённые и новые файлы в Блокноте. Перенесите свои строки в одноимённые файлы новой папки `lists`, нажмите `Ctrl + S` и [перезапустите стратегию](#как-выключить-и-включить-zapret).

<details>
<summary>Как проверить и убрать оставшуюся службу</summary>

Откройте "Пуск", введите `cmd` и выберите "Запуск от имени администратора". Выполните команды по одной. Ошибка `1060` означает, что указанной службы уже нет.

```cmd
sc query zapret
sc query GoodbyeDPI
driverquery | findstr /I Divert
```

Если обнаружили именно старую службу `zapret`, сначала проверьте её путь командой `sc qc zapret`. Поле `BINARY_PATH_NAME` должно указывать на старую сборку. Тогда выполните `sc stop zapret`, затем `sc delete zapret`. Для ненужной службы GoodbyeDPI действуйте так же, подставив `GoodbyeDPI`. WinDivert может использоваться другими сетевыми программами. Проверьте путь через `sc qc WinDivert`. После закрытия этих программ удаляйте оставшийся драйвер, если путь указывает на прежнюю установку. Подставьте подтверждённое имя вместо `WinDivert`, если в выводе указано другое.

```cmd
sc stop WinDivert
sc delete WinDivert
```

Если служба помечена для удаления, перезагрузите Windows и повторите `sc query` с её именем. Затем вернитесь к [быстрому старту](../README.md#быстрый-старт). [Удаление службы и WinDivert в README](https://github.com/Flowseal/zapret-discord-youtube/blob/1.10.4/README.md) · [Как работает Remove Services](https://github.com/Flowseal/zapret-discord-youtube/blob/1.10.4/service.bat#L194-L225)

</details>

## Настройки сети

### Безопасный DNS

| Где | Что нажать |
| --- | --- |
| **Яндекс Браузер** | `browser://protect` --> "Использовать безопасный DNS-сервер" --> выберите поставщика. [Подробности и проверка](../README.md#yandex-browser) |
| **Chrome** | Откройте `chrome://settings/security` --> "Использовать безопасный DNS". Включите его, выберите конкретного провайдера, например Google, затем снова откройте проблемный сайт. [Справка Chrome](https://support.google.com/chrome/answer/10468685) |
| **Firefox** | Откройте `about:preferences#privacy` --> найдите "DNS через HTTPS" --> "Персональная защита" или `Custom Protection` --> выберите провайдера. В поле для своего поставщика можно указать `https://dns.google/dns-query`. [Справка Firefox](https://support.mozilla.org/en-US/kb/dns-over-https) |
| **Edge** | Откройте меню --> "Настройки". В поиске по настройкам введите "безопасный DNS", откройте найденный пункт и выберите провайдера из списка. |
| **Windows 11 для приложений** | `Win + I` --> "Сеть и Интернет" --> свойства текущего Wi-Fi или Ethernet. Рядом с назначением DNS нажмите "Изменить" --> "Вручную" --> IPv4. Пример для Google DNS - `8.8.8.8` и `8.8.4.4`. Для DNS через HTTPS выберите автоматический шаблон, если он доступен, затем нажмите "Сохранить". Если после правки перестали открываться обычные сайты, верните прежние значения или "Автоматически (DHCP)", если этот режим стоял раньше. [Настройки сети Windows](https://support.microsoft.com/en-gb/windows/experience/connectivity-networking/essential-network-settings-and-tasks-in-windows) · [Адреса Google Public DNS](https://developers.google.com/speed/public-dns/docs/using) |

После настройки откройте тот же сайт. Для проверки, какой DNS отвечает в браузере, откройте [DNSCheck](https://dnscheck.tools/) и посмотрите название обнаруженного резолвера. Если браузер показывает ошибку DNS, верните предыдущего поставщика или попробуйте другой из списка.

### Прокси через inetcpl.cpl

1. Нажмите `Win + R`, введите `inetcpl.cpl` и нажмите Enter.
2. Откройте вкладку "Подключения" и нажмите "Настройка сети".
3. Если на этом компьютере вы подключаетесь напрямую, проверьте настройки по таблице. Перед изменениями запишите текущие значения. Если прокси или сценарий настроены для работы или учёбы, сохраните эти параметры.
4. Нажмите "ОК" в окне "Настройка сети", затем "ОК" в свойствах браузера. Закройте и заново откройте приложение, в котором был сбой.

| Параметр | Что проверить при прямом подключении |
| --- | --- |
| "Использовать прокси-сервер для локальных подключений" | Снимите галочку, если прокси остался от старой программы и больше не нужен. |
| "Использовать сценарий автоматической настройки" | Снимите галочку, если указанный сценарий больше не используется. |
| "Автоматическое определение параметров" | Обычно можно оставить включённым. Если хотите проверить подключение без автообнаружения прокси, временно снимите галочку и сравните результат. |

Те же пользовательские параметры можно проверить через "Параметры" --> "Сеть и Интернет" --> "Прокси-сервер". Отдельно проверьте прокси WinHTTP командой `netsh winhttp show proxy` в CMD. Некоторые приложения используют его для своих запросов. Если он остался от старой настройки, команда сброса есть ниже. [Настройки прокси Windows](https://support.microsoft.com/en-us/windows/experience/connectivity-networking/use-a-proxy-server-in-windows) · [Команды WinHTTP](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/netsh-winhttp)

### Конфликтующие программы, службы и адаптеры

- **VPN, TUN и другие обходы.** Для сравнения по одному выключите WARP, Happ, OpenVPN, WireGuard, TunnelBear, Mullvad, Proxifier или другой клиент, который у вас запущен. Проверьте то же действие, затем верните нужную программу. WARP может работать вместе с zapret, но результат зависит от режима и стратегии. Если сбой возникает только при совместном запуске с WARP или Happ, зафиксируйте режим и название виртуального интерфейса. [WARP #10489](https://github.com/Flowseal/zapret-discord-youtube/discussions/10489) · [Happ и RustDesk #18507](https://github.com/Flowseal/zapret-discord-youtube/issues/18507)
- **AdGuard Desktop.** В главном окне временно выключите защиту и повторите звонок. Если это помогло, откройте "Настройки" --> "Сеть" --> "Список фильтруемых приложений". Через `+` --> "Выбрать исполняемый файл" добавьте `bin\winws.exe` из папки zapret. Найдите Discord в том же списке, снимите галочки с обеих программ, затем включите защиту и повторите звонок. Если Discord отсутствует, при работающем клиенте откройте Диспетчер задач --> "Подробности" --> правой кнопкой по `Discord.exe` --> "Открыть расположение файла". Добавьте найденный файл через тот же `+`. [Случай #13149 с картинками](https://github.com/Flowseal/zapret-discord-youtube/issues/13149)
- **Intel/Rivet Killer.** В Killer Control Center найдите "Bandwidth Control" или "Advanced Stream Detect", если такой переключатель есть. Временно выключите его и перепроверьте соединение. Верните прежнее значение, если оно не влияет на сбой. [Обсуждение #252](https://github.com/Flowseal/zapret-discord-youtube/discussions/252)
- **Службы.** Нажмите `Win + R` --> `services.msc`. Найдите службу Killer, SmartByte, Check Point, Cisco AnyConnect или своего VPN. Дважды нажмите по ней и на вкладке "Общие" запишите "Тип запуска" и проверьте путь к исполняемому файлу. Нажмите "Остановить" и повторите тест. Если конфликт подтвердился, а программа запускает ненужную вам службу снова, выберите "Отключена" --> "Применить". Для отката верните прежний тип --> "Применить" --> "Запустить". Для корпоративного VPN или сетевой защиты сохраните настройки организации.
- **Виртуальные адаптеры.** Откройте `Win + R` --> `devmgmt.msc` --> "Сетевые адаптеры". Найдите адаптер конкретной программы, например Radmin VPN, Hamachi или TAP-Windows Adapter V9. Для теста нажмите правой кнопкой и выберите "Отключить устройство". Если сбой исчез и адаптер остался от уже удалённой программы, можно удалить именно это устройство. Для восстановления действующего адаптера включите его обратно, а после удаления используйте установщик его программы. Если Radmin VPN или Hamachi нужны для игр и конфликт подтверждён, проверьте их отдельно при выключенном zapret. [Отчёт о виртуальных адаптерах #4201](https://github.com/Flowseal/zapret-discord-youtube/issues/4201)

### Сброс сети из CMD

Проверьте этот блок, если сбой появился после VPN или прокси, сеть пропадает после перезагрузки либо Epic Games Launcher уходит в автономный режим. Сначала [сравните запуск с zapret и без него](#как-выключить-и-включить-zapret). В "Пуске" найдите `cmd` --> "Запуск от имени администратора". Если настраивали сеть вручную, выполните `ipconfig /all` и запишите IP, маску, шлюз и DNS из блока своего адаптера. Прокси сохраните отдельно по [настройкам выше](#прокси-через-inetcplcpl). Затем вводите команды сброса по одной и нажимайте Enter.

Если вы меняли только DNS или `hosts`, начните с последней команды. Строку `netsh winhttp reset proxy` выполняйте, когда нужно вернуть WinHTTP на прямое подключение. Две команды `netsh interface` относятся к расширенному сбросу IPv4 и IPv6.

```cmd
netsh int ip reset
netsh winhttp reset proxy
netsh winsock reset
netsh interface ipv4 reset
netsh interface ipv6 reset
ipconfig /flushdns
```

После сброса TCP/IP или Winsock перезагрузите ПК и повторите проверку. [Сброс TCP/IP в Windows](https://learn.microsoft.com/en-us/troubleshoot/windows-server/networking/reset-tcp-ip-net-shell) · [Команды Winsock](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/netsh-winsock) · [README Flowseal](https://github.com/Flowseal/zapret-discord-youtube/blob/1.10.4/README.md)

<details>
<summary>Отдельная настройка диапазона TCP-портов из исходного гайда</summary>

Если проверяете именно эту настройку, сначала запишите исходные значения `Start Port` и `Number of Ports`. Первая команда показывает текущий диапазон, вторая задаёт диапазон из исходного поста.

```cmd
netsh int ipv4 show dynamicport tcp
netsh int ipv4 set dynamicport tcp start=10000 num=30000
```

Для отката подставьте сохранённые значения в ту же команду `set dynamicport`. Стандартный диапазон Windows начинается с `49152` и содержит `16384` порта. Если до изменения стояли стандартные значения, команда отката выглядит так.

```cmd
netsh int ipv4 set dynamicport tcp start=49152 num=16384
```

[Диапазон динамических портов Windows](https://learn.microsoft.com/en-us/troubleshoot/windows-server/networking/default-dynamic-port-range-tcpip-chang)

</details>

## Как выключить и включить zapret

| Режим | Выключить | Включить обратно |
| --- | --- | --- |
| Через BAT | Закройте окно стратегии с замочком на панели задач. Если окна нет, нажмите `Ctrl + Shift + Esc` --> "Подробности" (на Windows 7 - "Процессы") --> `winws.exe` --> "Снять задачу". | Дважды нажмите тот же `general*.bat`. |
| Через службу | Откройте `service.bat` --> `3. Check Status` и запишите имя стратегии. Вернитесь в меню --> `2. Remove Services`. Этот пункт удаляет службу из автозапуска. | Откройте `service.bat` --> `1. Install Service` --> введите номер записанной стратегии. Затем откройте `3. Check Status` и проверьте, что zapret запущен. |

**Перезапуск установленной службы.** Откройте `service.bat` --> `1. Install Service` и выберите тот же BAT. Скрипт сам остановит текущую службу, переустановит её и запустит снова. Если хотите сразу сменить стратегию, выберите другой BAT в том же меню. Пункт `2. Remove Services` нужен, когда хотите выключить zapret и убрать его из автозапуска. [Код переустановки службы](https://github.com/Flowseal/zapret-discord-youtube/blob/1.10.4/service.bat#L345-L364)

Для контроля откройте `service.bat` --> `3. Check Status`. С выключенным zapret ожидайте `Bypass (winws.exe) is NOT running`, если на ПК нет другого экземпляра winws. Откройте тот же сайт, ролик или приложение до и после включения и сравните один и тот же шаг. [Код проверки статуса](https://github.com/Flowseal/zapret-discord-youtube/blob/1.10.4/service.bat#L140-L190)
