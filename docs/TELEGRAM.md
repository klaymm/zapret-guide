# Telegram и системный hosts

[Оглавление](../README.md)

Этот раздел охватывает Telegram Web, Telegram Desktop и записи hosts для Discord.

## Hosts для Discord и Telegram

При первой настройке Discord или Telegram Web удобно добавить **весь официальный блок Flowseal**. В нём есть записи для Discord, его обновлений, Telegram и GitHub. Для Discord это может помочь, когда клиент не может обратиться к нужному узлу по имени. Если приложение уже открывается, а зависает только голос, дополнительно пройдите шаги для [RTC Connecting](TROUBLESHOOTING.md#discord). Текущий файл содержит записи для `discord.com` и `updates.discord.com`. [Официальный hosts](https://github.com/Flowseal/zapret-discord-youtube/blob/main/.service/hosts) · [Описание пункта Update Hosts File](https://github.com/Flowseal/zapret-discord-youtube/blob/1.10.4/README.md)

1. Нажмите `Win + R`, введите `%SystemRoot%\System32\drivers\etc` и нажмите Enter. Скопируйте файл `hosts` в отдельную папку, например в "Загрузки".
2. Откройте `service.bat` --> `9. Update Hosts File`. Если скрипт пишет `Hosts file needs to be updated`, он откроет скачанный список в Блокноте. Выделите весь текст через `Ctrl + A` --> `Ctrl + C`. Если окно не открылось, откройте [официальный файл](https://github.com/Flowseal/zapret-discord-youtube/blob/main/.service/hosts) и нажмите `Raw`, затем скопируйте весь текст. Сообщение `Hosts file is up to date` означает, что скрипт нашёл первую и последнюю строки. При необходимости проверьте блок целиком.
3. Откройте "Пуск", найдите "Блокнот" --> "Запуск от имени администратора". Нажмите `Ctrl + O`, вставьте полный путь к системному `hosts` и нажмите Enter. Если выбираете файл через диалог, переключите тип на "Все файлы". Вставьте весь официальный блок в конец. Если он уже был, замените старый блок, оставив остальные строки файла. Если прежде добавляли отдельные записи для тех же имён, уберите старые совпадающие строки. Несколько IP одного имени внутри нового блока оставьте как в источнике.
4. Нажмите `Ctrl + S` и проверьте, что файл называется `hosts` без `.txt`. В CMD выполните `ipconfig /flushdns`. Полностью закройте Discord через значок рядом с часами и запустите заново. В [Telegram Web](https://web.telegram.org/) обновите вкладку через `Ctrl + F5`. Если доступ ухудшился, верните сохранённый `hosts` с заменой и снова выполните `ipconfig /flushdns`. [Код обновления hosts](https://github.com/Flowseal/zapret-discord-youtube/blob/1.10.4/service.bat#L1143-L1209)

В одном из отчётов Telegram Web заработал после обновления записей. Для повторной настройки берите текущий официальный блок из шага 2. [Отчёт автора об обновлении](https://github.com/Flowseal/zapret-discord-youtube/issues/11409)

## Telegram Desktop

1. В [релизах tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy/releases/latest) скачайте файл для вашей системы. Для Windows 10/11 x64 это `TgWsProxy_windows.exe`. Тип системы указан в `Win + I` --> "Система" --> "О системе".
2. Запустите файл. Нажмите правой кнопкой по значку прокси рядом с часами --> "Открыть в Telegram". В Telegram подтвердите подключение. Если меню предлагает только копирование ссылки, скопируйте её, вставьте в "Избранное" и нажмите по ней.
3. Откройте один и тот же чат и проверьте отправку сообщения и загрузку файла отдельно. Для отключения прокси в Telegram откройте "Настройки" --> "Продвинутые настройки" --> "Тип подключения" --> настройки прокси. Выключите локальный прокси и закройте TgWsProxy через значок рядом с часами. [Документация Flowseal](https://github.com/Flowseal/tg-ws-proxy)
