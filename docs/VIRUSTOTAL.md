# Проверка файлов zapret

[Оглавление](../README.md)

Здесь описано, как сверить скачанный архив с релизом и разобраться с детектом.

## Антивирус и VirusTotal

### Как сверить архив и найти отчёт

1. В Проводнике откройте папку, куда скачали ZIP. В адресной строке введите `powershell` и нажмите Enter. Для официального ZIP 1.10.4 выполните команду ниже. Если имя отличается, подставьте своё.

   ```powershell
   Get-FileHash -LiteralPath '.\zapret-discord-youtube-1.10.4.zip' -Algorithm SHA256
   ```

2. Сравните поле `Hash` с SHA-256 ZIP из официального релиза 1.10.4. Регистр букв значения не имеет.

   ```text
   291af673bd0238506f9548e0e94ca0abf244000f4c9a06960544fb01c5f97b34
   ```

   Совпадение подтверждает, что байты вашего ZIP совпадают с указанным релизным файлом. Если сумма отличается, проверьте версию и формат архива. Для ZIP той же версии скачайте файл заново из Assets. Для RAR откройте данные релиза по ссылке ниже, нажмите `Ctrl + F`, найдите точное имя архива и сравните значение `digest` у этого файла. Для другой версии откройте данные её релиза, заменив номер версии в конце адреса. [Релиз 1.10.4](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.4) · [Данные GitHub Releases с SHA-256](https://api.github.com/repos/Flowseal/zapret-discord-youtube/releases/tags/1.10.4)

3. Если антивирус указал конкретный файл, вычислите SHA-256 этого файла отдельно. Из папки zapret для драйвера команда выглядит так. Для другого файла подставьте его путь.

   ```powershell
   Get-FileHash -LiteralPath '.\bin\WinDivert64.sys' -Algorithm SHA256
   ```

4. Откройте [VirusTotal](https://www.virustotal.com/gui/home/search) --> `Search`, вставьте SHA-256 и нажмите Enter. В отчёте откройте `Detection` для списка движков и их названий, `Details` для сверки SHA-256, `Behavior` для результатов запуска в песочнице, если вкладка доступна. Отчёт для ZIP и отчёт для файла внутри него будут разными. Если отчёта по хэшу нет, начните со сверки официального архива и проверки локальным антивирусом. Публичная загрузка в VirusTotal может раскрыть содержимое файла другим участникам сервиса, поэтому для личных файлов, логов и конфигов используйте поиск по хэшу. [Поиск VirusTotal](https://docs.virustotal.com/docs/searching) · [Как устроены отчёты](https://docs.virustotal.com/docs/results-reports) · [Как сервис обрабатывает загрузки](https://docs.virustotal.com/docs/how-it-works)

### Как читать детекты WinDivert

WinDivert - драйвер перехвата сетевых пакетов. Zapret использует его для работы с трафиком. Такой инструмент может встречаться и в других программах, поэтому отдельный движок может отметить его как `RiskTool`, `PUA` или указать имя `WinDivert`. Даже знакомое название детекта само по себе ничего не говорит о происхождении файла. Сверяйте три вещи - источник, SHA-256 и точный файл из отчёта. [README Flowseal](https://github.com/Flowseal/zapret-discord-youtube/blob/1.10.4/README.md) · [Проект WinDivert](https://github.com/basil00/WinDivert)

| Что видно | Что сделать |
| --- | --- |
| `0/N` | Движки в отчёте не отметили образец. Сверьте источник и SHA-256, даже если число ноль. |
| Несколько меток `RiskTool` или `PUA` у файла из `bin` | Проверьте, совпадает ли хэш с тем же файлом, заново извлечённым из сверенного официального ZIP. Посмотрите, что именно детектируют движки. |
| Детект у неожиданного EXE или BAT, отличающийся хэш, подозрение на троян или стилер | Оставьте файл в карантине. Запишите название угрозы, путь и имя архива. Скачайте чистый ZIP с официального релиза и проверьте его отдельно. Если запускали подозрительную сборку, в "Безопасности Windows" откройте "Защита от вирусов и угроз" --> "Параметры сканирования" --> "Полное сканирование". |

Чтобы выяснить, что удалил Defender, откройте "Пуск" --> "Безопасность Windows" --> "Защита от вирусов и угроз" --> "Журнал защиты". Разверните запись за время распаковки и посмотрите название детекта и путь. Если считаете детект ошибочным, отправьте хэш и данные детекта разработчику своего антивируса. При установке используйте файл из проверенного официального архива.
